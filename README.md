# BMPSnake

BMPSnake started as a goof, because everyone likes BMP images, right? Originally I was gonna try a handful of things, then I decided, meh snake is fun.  
## How To Play
Google snake for that, but to actually play/use this project I would suggest opening it up in VSCode, as VSCode has an image viewer that can update dynamically as it changes. You can set the size variable up at the top to playing field size, I would disreccomend going above 200. Use WASD to move.
